# Tasks: Task 26, the third case, a reveal.js slide deck with sound control

The work has three stages and two commits. Order is test-first inside every stage: write the test, see it fail for the right reason, then write the code. Only stage 2 is measured. Its start is the start of the 2a run and its end is the 2c commit, so do not commit, and do not edit `cases/slides/src/main.ts`, between 2a and the end of 2b.

Rules for every step. Write English only. Do not run `git push`, `npm publish`, `npm login` or a workflow, and do not change repository settings. Do not add a dependency other than `reveal.js` at the exact version 6.0.2. Do not change `.kiro/agents/`, `.kiro/hooks/`, `.kiro/steering/integrate.md`, the integrate skill, `core/`, `web/`, `node/`, `tools/`, `docs/_planning/`, the plan, other specs or any runtime export. Do not edit anything under `node_modules`. Do not modify reveal.js; call only its public API. Apps and cases import only from `'tokk'`. Never send audio anywhere. Follow the units rule (names with units, no hard-coded sample count, every time `t` a sample count divided by the sample rate) and the privacy rule (feature vectors only in `sounds.json`, recordings only in local `sounds/` and `recordings/` folders). Write no duration, no hour and no credit of your own (requirement 16). Do not weaken or delete an existing test; a named update is allowed only where this file or the requirements name it, and it keeps a check that fails on a broken input. If a test shows that a rule of `requirements.md` or `design.md` is wrong, change those documents first and say why in `docs/devlog.md`. If installed Chrome cannot be launched by Playwright, stop and report; do not download a browser. Stop a running dev server before `test:web` and start the browser tests only after `cases/slides/src/main.ts` exists, because the dev server finds apps and cases at its start only. Record each item of "Measured values" in `design.md` as it is measured. Remove every temporary file and folder you create outside the intended changes.

After every step that touches code, `npm test`, `npx tsc --noEmit`, `npx tsc -p tsconfig.web.json --noEmit` and `npx tsc -p tsconfig.test-web.json --noEmit` must still pass (apart from the new tests that are meant to fail), and `check:public-api` must pass.
