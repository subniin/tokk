Tokk

Teach it a sound. Bind a pattern. Ship.

What it is

A small library that lets a web page react to short sounds, such as a knock or a whistle.

The sound model stays on the device that made it.

Teach a sound

Record about ten examples of one sound.

Tokk turns them into a small model of numbers, and the page can then tell that sound from the others.

Bind a pattern

A pattern is a few sounds in a row, and each pattern gets one action.

PatternAction
knock knockanswer yes
whistle, then knockstop

Your audio stays here

Nothing is sent anywhere.

The page keeps no recording. It keeps only numbers that describe each sound.

Try it
